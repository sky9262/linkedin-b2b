# Local Browser Principles

The local browser is used for operator-supervised research, not bypass.

## Allowed

- Open user-provided or source-backed URLs.
- Read visible content.
- Use company People tab search box when already on a company page.
- Extract visible cards to avoid manual copying errors.
- Save evidence and confidence.

## Not allowed

- Hidden API calls.
- Cookie extraction.
- Proxy rotation.
- Fingerprint manipulation.
- Multi-account coordination.
- CAPTCHA bypass.
- Constructing unverified LinkedIn profile URLs.
